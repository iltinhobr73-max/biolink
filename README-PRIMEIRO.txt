COMO ABRIR O PROJETO

1. Extraia este ZIP.
2. Abra a pasta extraida.
3. Clique duas vezes em: INICIAR-PROJETO.bat
4. Espere instalar.
5. Quando aparecer Ready, abra no navegador:

   http://localhost:3000

Se quiser abrir no celular, use o IP do seu PC:

   http://192.168.0.7:3000

OBS: celular e PC precisam estar no mesmo Wi-Fi.

Se preferir fazer manualmente:

npm install
npm run dev -- -H 0.0.0.0
